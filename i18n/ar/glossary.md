# 用語集：العربية（ar）

Kotlin演習の対訳表。訳すときは、この表の訳語を使う。新しく訳語を決めた用語は、行を足す。全言語に共通の翻訳ルールは `skills/translate-teaching-materials/SKILL.md` にある。メモに「要確認」とある行は、訳語に自信がないもの。翻訳PRで確かめたら「要確認」を消す。

**アラビア語は右から左に書く。** 翻訳ページには `dir="rtl"` が付き、コード・キー・未翻訳の日本語は左から右のまま出る（#78）。向きはスクリプトとCSSが決めるので、訳文に向きを変える見えない文字（U+200E など）を入れない。右から左の文の中での記号の書き方は、下の「書き方の決まり」にある。

## IntelliJ IDEAの画面に出る日本語（K01。日本語のまま残し、訳をかっこで添える）

K01の教科書は、日本語表示の IntelliJ IDEA のメニュー名を書いている。画面の言葉は訳さずに残し、うしろにこの表の訳をかっこで添える（例：**新規 → パッケージ** (جديد ← حزمة)）。IntelliJ IDEA にアラビア語の表示はないので、この表の訳は実際の表示ではなく、意味を伝えるための訳である。原文が英語で書いている名前（**File → New → Project…** など）は英語のまま残す。かっこの中の経路の矢印を ← にする理由は、下の「書き方の決まり」にある。

| 画面の言葉 | かっこに添える訳 | 場所 |
| --- | --- | --- |
| 新規… | جديد… | ホーム画面のメニュー |
| 新規プロジェクト… / 新規プロジェクト | مشروع جديد… / مشروع جديد | ホーム画面のメニュー／新規プロジェクトの画面の見出し |
| 開く… | فتح… | ホーム画面のメニュー |
| ジェネレーター | المولِّدات | 新規プロジェクトの画面 |
| 場所 | الموقع | 新規プロジェクトの画面 |
| プロジェクト | المشروع | ツールウィンドウ |

## 書き方の決まり

- **現代標準アラビア語（الفصحى）で書く。** 方言は使わない。
- **手順は二人称単数の命令形で書く**（افتح الملف.、انقر **Run**.）。アラビア語の命令形は男女で形が変わるので、技術文書の慣例どおり男性形を使う。先生は المعلم と書く（`config/i18n.json` の翻訳の注記と同じ）。
- **数字は 0〜9 の字（1、2、3）で書く。** アラビア・インド数字（١، ٢، ٣）は使わない。STEPの番号・コマの数・行番号・画面に出る数字を、コードや画面と同じ字で見比べられるようにするため。
- **句読点はアラビア語のものを使う**（読点 ،、疑問符 ؟、セミコロン ؛）。文末はピリオド（.）。コードや英字の名前の中の記号は変えない。
- **引用符は «…»。** 画面やアプリに出る日本語を囲むときは「」のまま残してよい（翻訳skillのルール）。右から左の文の中でも、「」と «» は形が崩れずに出る（2026-09-25、Chromium系のブラウザで確かめた。Safariは未確認）。
- **手順の順番を示す矢印は ← にする**（غيّر شيئا واحدا ← توقّع ← شغّل）。読む向きが右から左なので、原文の → のままだと逆を指す。「次へ」のリンクの矢印も ← にする（الانتقال إلى K01：HelloKotlin ←）。
- **画面の名前をつないだ経路は、原文の言葉と → をそのまま残す**（**File → New → Project…**、**新規 → パッケージ**）。画面は左から右に並んでいるので、→ のままでよい。訳はうしろのかっこに添え、かっこの中の経路はアラビア語なので ← でつなぐ（**表示 → ツールウィンドウ → 実行** (عرض ← نوافذ الأدوات ← تشغيل)）。経路の途中の語だけを訳すと、向きの違う語が混ざって順番が読めなくなるので、経路の中は訳さない（**書類 → Kotlin → 自分のプロジェクト名** (المستندات ← Kotlin ← اسم مشروعك)）。
- **`<strong>` の中をアラビア語で書くときは、アラビア文字で書き始める。** 右から左のページでは、`<strong>` の向きは中身の最初の文字で決まる（`docs/assets/textbook.css`）。英字や日本語で始めると、その `<strong>` 全体が左から右に並ぶ。英字や日本語の画面の名前だけを入れるときは、そのままでよい。

ここから下は、この授業だけの決まり。

- 確認欄（ここで止まって確認）は、画面で確かめられる状態を現在形で書く（يظهر…、تُعرض…）。「〜できた」「〜と言えた」のような振り返りの言い方にしない。
- Kotlin固有の用語を定義する文では、訳語のうしろに日本語をかっこで添える（المُنشئ الأساسي (プライマリコンストラクタ)）。
- 全角の記号はASCIIにする（`＋` → `+`、`〜` の範囲 → en dash `–`）。サイドバーの「番号＋全角スペース＋題名」の全角スペースだけは残す。
- **「戻る」のリンクの矢印は → にする**（→ العودة إلى الصفحة الأصلية）。右から左に読むので、戻る向きは右になる。「次へ」の ← と逆になる。
- **URLをそのまま書いたリンクの文字は、末尾の / を落とす**（リンクの文字を `https://play.kotlinlang.org` にする。`href` は原文のまま変わらない）。右から左の文の中では、URLの最後の / が、URLの反対側（先頭の左）へ回り込んで見えるため（#81、Chromium系のブラウザで確かめた）。
- **母音記号（ハラカート・タンウィーン）は付けない**（أولا、تلقائيا）。読み違えやすい語だけ付けてよい（シャッダ：شغّل、نزّل。上の表の مُعامِل・المُنشئ）。jec-25cm-hybrid-app の用語集の下書き（あちらの PR #52）と同じ決まり。
- **英字の製品名やコード名に、定冠詞 ال を直接付けない。** 名詞を添えて書く（جهاز Mac、مشروع Kotlin）。これも jec-25cm-hybrid-app の下書きと同じ。
- 日付は 23 سبتمبر 2026 の形にする（月はグレゴリオ暦の名前 يناير … ديسمبر）。
- 表の見出し（使うもの、場所、項目など）は、同じ原文のほかのページの表にも同じ訳が入る。特定の表の中身に寄せず、どの表でも通じる言い方にする（使うもの → ما تستخدمه）。
