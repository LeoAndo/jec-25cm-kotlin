# 用語集：繁體中文（台灣）（zh-Hant-TW）

Kotlin演習の対訳表。訳すときは、この表の訳語を使う。新しく訳語を決めた用語は、行を足す。全言語に共通の翻訳ルールは `skills/translate-teaching-materials/SKILL.md` にある。メモに「要確認」とある行は、訳語に自信がないもの（とくに、台湾と香港・中国で言い方が分かれる語）。翻訳PRで確かめたら「要確認」を消す。

## IntelliJ IDEAの画面に出る日本語（K01。日本語のまま残し、訳をかっこで添える）

K01の教科書は、日本語表示の IntelliJ IDEA のメニュー名を書いている。画面の言葉は訳さずに残し、うしろにこの表の訳をかっこで添える（例：**新規 → パッケージ**（新增 → 套件））。日本語と同じ字になる言葉は、かっこ書きを添えない。翻訳skillは、かっこにはその言語で表示したIDEの名前を添えるとしているが、IntelliJ IDEA が同梱している中国語の言語パックは簡体字で（翻訳skillの「前提」）、台湾の繁体字の表示はない。そのため、この表の訳は台湾の語彙で書いた意味の訳である。簡体字の表示を字だけ繁体字に直したもの（新建、项目 → 項目 など）にはしない。原文が英語で書いている名前（**File → New → Project…** など）は英語のまま残す。

## 書き方の決まり

- **台湾で使う語彙にする。** 香港・中国の言い方と分かれる語は、次の表の「台湾」の列の訳を使う。

  | 日本語 | 台湾（この用語集） | 使わない言い方 |
  | --- | --- | --- |
  | コード | 程式碼 | 代碼 |
  | プログラム | 程式 | 程序 |
  | ソフトウェア | 軟體 | 軟件 |
  | ネットワーク | 網路 | 網絡 |
  | ファイル | 檔案 | 文件 |
  | フォルダ | 資料夾 | 文件夾 |
  | 画面・ディスプレイ | 螢幕 | 屏幕 |
  | マウス | 滑鼠 | 鼠標 |
  | デフォルト | 預設 | 默認 |
  | サーバー | 伺服器 | 服務器 |
  | サポートする | 支援 | 支持 |
  | インターフェース | 介面 | 界面 |
  | 情報 | 資訊 | 信息 |
  | メモリ | 記憶體 | 內存 |
  | オブジェクト | 物件 | 對象 |
  | 文字列 | 字串 | 字符串 |
  | 配列 | 陣列 | 數組 |
  | ループ | 迴圈 | 循環 |
  | 動画 | 影片 | 視頻 |

- **字形は台湾の字形にする。** 「這裡」「哪裡」のように 裡 を使う（香港の 裏 は使わない）。地名は 台灣 と書く。
- **引用符は「」、引用の中の引用は『』。** 台湾の書き方なので、日本語のかぎかっこと同じ形になる。
- 句読点は全角（，。：；？！（））にする。
