## IntelliJ IDEAの画面に出る日本語（K01。日本語のまま残し、訳をかっこで添える）

K01の教科書は、日本語表示の IntelliJ IDEA の画面の言葉を書いている。画面の言葉は訳さずに残し、うしろに IntelliJ IDEA を中国語（簡体字）で表示したときの名前を（）で添える（例：場所（位置））。表示名の末尾のコロン（`位置:` の `:`）は付けない。この表の表示名は、IntelliJ IDEA 2026.3 EAP（IU-263.5153.40）が同梱している中国語の言語パック（`localization-zh`）の `messages/*.properties` で、日本語の言語パック（`localization-ja`）と同じキーの値を読んで確かめた（2026-09-25、#99）。K01はまだ訳していないので、訳すときに使った画面の言葉を、この表に足す。

| 画面の言葉 | かっこに添える表示名 | 場所 |
| --- | --- | --- |
| 場所 | 位置 | 新規プロジェクトの画面。K01の表の `<td>場所</td>` は、準備ガイドなどの表の見出し `<th>場所</th>`（位置）と訳し分けるため、K01のカタログの `overrides` に置く（#99） |
| 名前 | 名称 | 新規プロジェクトの画面。ただしK01の表の `<td>名前</td>` は、引数の表（STEP 15）にも同じ形であり、訳し分けられない。表の `<td>名前</td>` は日本語を添えずに訳す（英語と同じ。#99） |

## Google Classroom と Finder の画面に出る日本語（apk。日本語のまま残し、訳をかっこに添える）

## 書き方の決まり

- 操作は短い指示文、確認欄は画面で確認できる結果を示す文にする。
- 通常の引用は“…”、中国語の句読点を使う。実際の日本語UIは「」ごと保持し、中国語の意味を毎回添える。
- macOSの日本語表示「書類」「ダウンロード」「アプリケーション」にはそれぞれ文稿、下载、应用程序を添える。
- 中国語と英字の語・コード（`<code>`・`<strong>` の英字）のあいだには半角スペースを入れる（在 Android Studio 中、打开 <code>app-debug.apk</code>）。中国語と算用数字のあいだには入れない（第1单元、步骤3、这4个）。中国語の句読点の前後にはスペースを入れない（setup と同じ）。
- 並べるときの中黒「・」は使わず、頓号「、」にする（`<code>main</code>、<code>text</code>`）。見出しの「A・B」は 与 でつなぐ（版を確かめる・サポートの範囲 → 确认版本与支持范围）。
- 範囲の「〜」は全角の波ダッシュ「～」（U+FF5E）にする（STEP 00～13）。
- `<code>` の中の日本語（`学籍番号`、`プロジェクトごとの名前`）を本文で指すときは、日本語のまま書いて意味を（）で添える（<code>学籍番号</code>（学号）、（プロジェクトごとの名前 指每个项目各自的名称））。
- IDE のボタン名を動詞に使う原文（Runして確かめる）は、点击 Run 确认 のように 点击 を補って書く。Run・Build・Open・Code・Project・locate などの英語の表示名は英語のまま。
