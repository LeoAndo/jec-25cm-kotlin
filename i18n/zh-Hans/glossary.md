## 書き方の決まり

- 操作は短い指示文、確認欄は画面で確認できる結果を示す文にする。
- 通常の引用は“…”、中国語の句読点を使う。実際の日本語UIは「」ごと保持し、中国語の意味を毎回添える。
- macOSの日本語表示「書類」「ダウンロード」「アプリケーション」にはそれぞれ文稿、下载、应用程序を添える。
- 中国語と英字の語・コード（`<code>`・`<strong>` の英字）のあいだには半角スペースを入れる（在 Android Studio 中、打开 <code>app-debug.apk</code>）。中国語と算用数字のあいだには入れない（第1单元、步骤3、这4个）。中国語の句読点の前後にはスペースを入れない（setup と同じ）。
- 並べるときの中黒「・」は使わず、頓号「、」にする（`<code>main</code>、<code>text</code>`）。見出しの「A・B」は 与 でつなぐ（版を確かめる・サポートの範囲 → 确认版本与支持范围）。
- 範囲の「〜」は全角の波ダッシュ「～」（U+FF5E）にする（STEP 00～13）。
- `STEP 04`・`K01`・`Panda 2`・`Android 12` のような英字と数字の語は、1つの英字の語として前後に半角スペースを入れる（在 STEP 04 遇到问题时、K01 完成）。裸の数字は空けない（第2节课、3个文件、500×416像素、练习A）。
- 科目名の `Kotlin练习` は、準備ガイドから使っている表記で、英字と中国語のあいだを空けない（例外）。
- 英字の語どうしを並べる全角の「／」は、半角の「 / 」にする（与 Java / Swift 的比较）。パスや IntelliJ IDEA の表示名（`Kotlin 类/文件`）は、表示どおり空けない。
- アプリや画面に出る日本語は「」ごと残して意味を（）で添える（「保存しました」（已保存））。簡体字でも同じ字で同じ意味になる語（「保存」、`条件`）には添えない。
- 確認欄は、済んだ操作を 已… で書き、画面で見える状態を続ける（控制台已输出这3行。）。「〜できた」の形にしない。
- フォルダの「直下」は 直接位于…中／直接…下 と書く（直接放在 <strong>drawable</strong> 文件夹里、直接创建在了 <code>src</code> 下）。正下方 は画面の上で見た目の真下を指すときだけに使う（<strong>場所</strong>（位置）栏正下方）。照合（PR #189）で、フォルダの1つ下の階層を 正下方 と書くと、ツリーの1つ下の行とも読めると挙がったため。
- 「再開」は、前回の続きから始める意味なので 继续 にする（继续上节课、从输入界面继续）。重新开始 は「最初からやり直す」に読める。
- `<code>` の中の日本語（`学籍番号`、`プロジェクトごとの名前`）を本文で指すときは、日本語のまま書いて意味を（）で添える（<code>学籍番号</code>（学号）、（プロジェクトごとの名前 指每个项目各自的名称））。
- IDE のボタン名を動詞に使う原文（Runして確かめる）は、点击 Run 确认 のように 点击 を補って書く。Run・Build・Open・Code・Project・locate などの英語の表示名は英語のまま。
