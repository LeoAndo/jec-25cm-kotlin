# 用語集：繁體中文（香港）（zh-Hant-HK）

Kotlin演習の対訳表。訳すときは、この表の訳語を使う。新しく訳語を決めた用語は、行を足す。全言語に共通の翻訳ルールは `skills/translate-teaching-materials/SKILL.md` にある。

## 教材と操作の用語

| 日本語 | 訳 | メモ |
| --- | --- | --- |
| Kotlin | Kotlin | 製品名。訳さない |
| IntelliJ IDEA | IntelliJ IDEA | 製品名。訳さない |
| Android Studio | Android Studio | 製品名。訳さない |
| プロジェクト | 專案 | |
| パッケージ | 套件 | `ex01` などのパッケージ名は訳さない |
| 関数 | 函式 | `fun main()` の表記は原文のまま |
| 変数 | 變數 | `val` / `var` の表記は原文のまま |
| 実行 | 執行 | ボタンの表示は Run を保持 |
| コンソール | 主控台 | 実行結果が出る場所。IntelliJ IDEAの画面名 Run は保持 |
| エミュレータ | 模擬器 | Android系の単元で使う |
