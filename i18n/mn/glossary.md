## 書き方の決まり

「ここから下は、この授業だけの決まり」の前までは、jec-25cm-hybrid-app の `i18n/mn/glossary.md`（main `9c01c82`）と同じ文面にしてある（#92）。変えるときは、あちらも同じように直す。例のうち `lib/main.dart`・**プレビュー**・Monaca は、あちらの教材の言葉である。

- **学生への呼びかけは、丁寧な та にする。** чи は使わない。複数の人に向けるときは та бүхэн。
- **手順は、丁寧な命令形「語幹＋-на уу／-нэ үү／-но уу／-нө үү」で書く。** どれを付けるかは、語幹の母音調和で決まる。

  | 動詞 | 手順の形 | 意味 |
  | --- | --- | --- |
  | дарах | дарна уу | 押す・クリックする |
  | нээх | нээнэ үү | 開く |
  | сонгох | сонгоно уу | 選ぶ |
  | өөрчлөх | өөрчилнө үү | 変える |
  | хуулах | хуулна уу | コピーする |
  | шалгах | шалгана уу | 確かめる |
  | үүсгэх | үүсгэнэ үү | 作る |
  | хадгалах | хадгална уу | 保存する |
  | ажиллуулах | ажиллуулна уу | 実行する |

  語幹だけの命令形（дар、нээ）はぶっきらぼうなので使わない。-аарай／-ээрэй（дараарай）は話し言葉の頼み方なので、教科書では使わない。
- **説明の文は、書き言葉の平叙文で終える**（…байна、…болно、…юм）。話し言葉の文末（…шүү、…даа）は使わない。
- **モンゴル語だけの文字を正しく使う。** 使うのは Ө ө（U+04E8／U+04E9）と Ү ү（U+04AE／U+04AF）。次の似た文字で代用しない。

  | 正しい文字 | 代用してはいけない文字 |
  | --- | --- |
  | Ө ө（U+04E8／U+04E9） | ロシア語の О о、ラテン文字の O o、古い文字の Ѳ ѳ（U+0472／U+0473） |
  | Ү ү（U+04AE／U+04AF） | ロシア語の У у（モンゴル語では別の字で、別の音）、ラテン文字の Y y、カザフ語の Ұ ұ（U+04B0／U+04B1） |

  У と Ү はモンゴル語では別の文字なので、取り違えると別の語になる（уу と үү は、付く語幹の母音で決まる）。
- **ロシア語由来の語は、モンゴル語のつづりで書く。** 語末の -ия・-а・-ь を落とす形が多い（функц、програм、платформ、консол）。ロシア語の形（функция、программа、платформа、консоль）では書かない。
- **英字の語やコードに格語尾を直接付けない。** うしろにモンゴル語の名詞（товч、цэс、файл、хавтас、төсөл、функц）を置き、格語尾はその名詞に付ける（**Run** товчийг дарна уу。`lib/main.dart` файлыг нээнэ үү。`<code>setState</code>` функцийг）。日本語のまま残した画面の言葉のうしろも同じにする（**プレビュー** цонхыг нээнэ үү）。名詞を置けないときだけ、ハイフンでつないで、その語を読んだ音で格語尾を選ぶ（Monaca-г）。
- **引用符は «…»、引用の中の引用は “…”。** 画面やアプリに出る日本語を囲むときは「」のまま残してよい（翻訳skillのルール）。
- **見出しは文頭だけ大文字にする。** 英語のように各語の頭を大文字にしない。
- **言語名と民族名は、文の途中では小文字で書く**（монгол хэл、япон хэл、англи хэл）。国名は大文字（Монгол Улс、Япон）。「日本語版」は япон хэлний хувилбар。言語切替に出る言語の名前（`config/i18n.json` の `name`、Монгол）は、表示名なので大文字のまま。
- **順番を表す数は「数字-р」で書く**（2-р хичээлийн цаг）。`STEP 3` はそのまま残す。
- 学生は оюутан、先生は багш。どちらも男女で形が変わらない。`config/i18n.json` に `mn` を足すときは、翻訳の注記（…багшаасаа асууна уу）もこの書き方にそろえる。

ここから下は、この授業だけの決まり。

- 上の「格語尾を直接付けない」の、この授業での例：**Run** товчийг дарна уу、`main.kt` файлыг нээнэ үү、**新規 → パッケージ** цэсийг сонгоно уу。
- 確認欄（ここで止まって確認）は、画面で確かめられる状態を現在形で書く（…харагдана、…гарч ирнэ）。「〜できた」「〜と言えた」のような振り返りの言い方にしない。
- Kotlin固有の用語を定義する文では、訳語のうしろに日本語をかっこで添える（үндсэн конструктор (プライマリコンストラクタ)）。
- 全角の記号はASCIIにする（`＋` → `+`、`〜` の範囲 → en dash `–`）。サイドバーの「番号＋全角スペース＋題名」の全角スペースだけは残す。
