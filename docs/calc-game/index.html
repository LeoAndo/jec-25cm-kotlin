使うIDEは Android Studio Panda 2、作るプロジェクトは A02CalcGame です。9コマ目で計時と停止・再開、10コマ目で10問の出題と採点を作ります。比較欄のJava／Swiftは読むためのもので、Kotlinのファイルには貼りません。

Viewを取得し、経過時間を保存する場所を用意する

app/src/main/java/jp/ac/jec/a02calcgame/MainActivity.kt を開き、全文を次で置き換えます。まずは画面とKotlinをつなぐところまでです。

MainActivity.kt · STEP 03終了時の全文
package jp.ac.jec.a02calcgame

import android.os.Bundle
import android.os.SystemClock
import android.widget.Button
import android.widget.Chronometer
import android.widget.TextView
import androidx.activity.enableEdgeToEdge
import androidx.appcompat.app.AppCompatActivity
import androidx.core.view.ViewCompat
import androidx.core.view.WindowInsetsCompat

class MainActivity : AppCompatActivity() {
    private var elapsedTimeMillis: Long = 0 // タイマーの経過時間(ms)
    private lateinit var txtMessage: TextView // メッセージの表示欄。onCreate以外のメソッドからも使うためフィールドにする

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        this.enableEdgeToEdge()
        setContentView(R.layout.activity_main)
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main)) { v, insets ->
            val systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars())
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom)
            insets
        }

        // Viewのインスタンスを取得する
        val chronometer: Chronometer = findViewById(R.id.chronometer)
        txtMessage = findViewById(R.id.txt_message)
        val btnStart: Button = findViewById(R.id.btn_start)
        val btnStop: Button = findViewById(R.id.btn_stop)
        val btnReset: Button = findViewById(R.id.btn_reset)

    }
}

Runして同じ画面が出ることを確かめます。elapsedTimeMillis は停止した瞬間までの経過時間をミリ秒で保存する場所です。txtMessage は、次のコマで onCreate の外に書く出題メソッドからも使います。ほかのViewは onCreate の中で使うのでローカル変数にします。

STEP 04 · 9コマ目 · 目安 15分

STARTで時間を進める

import の一覧に import android.os.SystemClock があることを確かめます。onCreate の val btnReset の行の後、onCreate を閉じる } の前に、次を追加します。

MainActivity.kt · onCreateの末尾へ追加
        // Startボタンを押下した時の処理
        btnStart.setOnClickListener { _ ->
            chronometer.setBase(SystemClock.elapsedRealtime() - elapsedTimeMillis)
            chronometer.start()
            btnStop.setEnabled(true)
            btnStart.setEnabled(false)
            btnReset.setEnabled(false)
        }

RunしてSTARTを押します。00:00 から秒が進み、START・RESETが押せなくなり、STOPが押せる色になります。STOPの処理は次のSTEPで書くため、今は止まりません。Android StudioのStop ■でアプリを終了してから次へ進みます。

SystemClock.elapsedRealtime() は端末起動後の経過ミリ秒です。時計の「何時何分」ではありません。Chronometerは「今の経過ミリ秒 − 基準時刻」を表示するので、初回は今を基準にして0から始めます。

Java／Swiftとの比較

Kotlin

btnStart.setOnClickListener { _ ->
    chronometer.start()
}

Java

btnStart.setOnClickListener(v -> {
    chronometer.start();
});

POINT

Kotlinの { _ -> … } はJavaのクリック用ラムダに相当します。_ は受け取ったViewを使わない印です。start() だけでは基準時刻を設定しないため、その直前に setBase を呼びます。

STEP 05 · 9コマ目 · 目安 17分

STOPで止め、STARTで再開し、RESETで戻す

STARTのリスナを閉じる } の後、onCreate の内側に、STOPとRESETの処理を続けて追加します。STARTのラムダの内側には入れません。

MainActivity.kt · STARTのリスナの後へ追加
        // Stopボタンを押下した時の処理
        btnStop.setOnClickListener { _ ->
            chronometer.stop()
            elapsedTimeMillis = SystemClock.elapsedRealtime() - chronometer.getBase()
            btnStop.setEnabled(false)
            btnStart.setEnabled(true)
            btnReset.setEnabled(true)
        }

        // Resetボタンを押下した時の処理
        btnReset.setOnClickListener { _ ->
            chronometer.stop()
            chronometer.setBase(SystemClock.elapsedRealtime())
            btnStop.setEnabled(false)
            btnStart.setEnabled(true)
            btnReset.setEnabled(false)
            txtMessage.text = ""
            elapsedTimeMillis = 0
        }
  1. Run→STARTで5秒ほど動かし、STOPを押します。
  2. 5秒待ちます。表示が進まないことを見ます。
  3. STARTを押します。停止前の秒数の続きから進みます。
  4. STOP→RESETを押します。時間が 00:00 に戻ります。
操作計算例（ミリ秒）
STOP保存する経過時間 = 今 − 基準時刻105000 − 100000 = 5000
5秒待ってSTART新しい基準時刻 = 今 − 保存した経過時間110000 − 5000 = 105000
再開直後の表示今 − 新しい基準時刻110000 − 105000 = 5000（5秒）

Java／Swiftとの比較

Kotlin

elapsedTimeMillis =
    SystemClock.elapsedRealtime() - chronometer.getBase()
btnStart.setEnabled(true)

Java

elapsedTimeMillis =
    SystemClock.elapsedRealtime() - chronometer.getBase();
btnStart.setEnabled(true);

POINT

stop() は表示の更新を止めますが、基準時刻を書き換えません。STOPで経過時間を保存し、STARTで基準時刻をずらすことで、休んだ時間を除きます。Javaと同じAPIなので getBase()・setEnabled() の書き方をそのまま使えます。

STEP 08 · 10コマ目 · 目安 15分

問題の状態と、1問を作るメソッドを追加する

class MainActivity の内側、onCreate より前に、次の4行を追加します。前回の elapsedTimeMillis と txtMessage は残します。

MainActivity.kt · クラスのプロパティへ追加
    private var nowNo = 1 // 今の問題が何問目かのカウント数
    private var correctNo = 0 // 正解数
    private var answer = 0 // 計算結果の答え
    private var isPlaying = false // ゲーム中かどうかのフラグ (Chronometer#mStartedフラグを取得できないため用意)

ファイル上部の import 一覧へ import java.util.concurrent.ThreadLocalRandom を追加します。次のメソッドは、onCreateを閉じる } の後、MainActivityを閉じる最後の } の前に追加します。

MainActivity.kt · onCreateの外、クラスの内側へ追加
    /**
     * 問題を開始する
     */
    private fun startQuestion() {
        val randomNumber = ThreadLocalRandom.current().nextInt(1, 10)
        // var randomNumber = RandomGenerator.getDefault().nextInt(1, 10); // API Level 35から利用可能. OSバージョンの分岐は使わない
        answer = 10 - randomNumber
        val message = nowNo.toString() + "問目: 10 - " + randomNumber + " ="
        txtMessage.text = message
    }

nextInt(1, 10) は1を含み、10を含まないので1〜9です。10 - randomNumber の答えも1〜9になります。nowNo は問題番号、correctNo は正解数、answer は現在の答え、isPlaying は数字への回答を受け付ける状態です。

Runしてタイマーが動くことを確かめます。ここでは startQuestion() をまだ呼んでいないため、問題欄は空白です。メソッド名に赤い波線がなければ次へ進みます。

private fun startQuestion() {

}
