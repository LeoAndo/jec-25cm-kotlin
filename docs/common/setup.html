KOTLIN PROGRAMMING EXERCISES / 共通資料・授業サポート

授業を始めるまでの
準備

教材を受け取ってから、授業を始めるまでの準備です。上から順に1回だけ行います。教材を「書類」に置き、使うアプリが入っていることを確かめます。2回目からは、教科書を開くところから始められます。

この資料の流れ

① 教材を受け取る→② 使うものを確かめる→③ 後半の準備を知る

番号は、下の見出しの番号と同じです。②では、使うアプリがMacに入っていることを確かめます。うまくいかないときは、いちばん下の「4. うまくいかないとき」を見てください。

プロジェクトの作成と実行は教科書で行います

Kotlinのプロジェクトの作り方や、コードの書き方・実行のしかたは、第1単元（K01：HelloKotlin）の教科書で順を追って説明します。この資料では、教材の配置とアプリの確認だけを行います。

この準備が終わると

教材が手元にそろい、授業で使うアプリが開ける状態になります。ここまでできれば、第1単元の教科書を開いて始められます。

1. 教材を受け取り、「書類」に置く

授業で使う教科書は、ZIPファイル1つにまとめて Google Classroom で配られます。ダウンロードして、置き場所を決めるところまでを行います。

  1. ブラウザで Google Classroom を開き、この授業のクラスを選びます。先生が投稿した教材のお知らせに、ZIPファイルが添付されています。
  2. 添付されたZIPファイルをクリックして、ダウンロードします。
  3. Finderを開き、左側の ダウンロード をクリックします。
  4. いちばん上に、今ダウンロードしたものがあります。次の2つのどちらかです。
ダウンロードにあるものすること
名前が .zip で終わるファイルダブルクリックします。同じ名前のフォルダができます。
すでにフォルダになっているそのままで大丈夫です。ZIPファイルが自動で展開され、同じ名前のフォルダができています。

どちらの場合も、最後はフォルダが1つある状態になります。名前には、次のように日付と12文字の英数字が入ります。

ZIPファイルの名前の例
kotlin-student-materials-2026-09-23-a81c6585fd87.zip
展開してできるフォルダの名前の例
kotlin-student-materials-2026-09-23-a81c6585fd87

日付と、そのうしろの12文字の英数字で教材の版を見分けます。同じ日に配られた教材でも、末尾が違えば別の版です。配られた版によって変わるので、上の例と同じ名前でなくても構いません。

新しい教材が配られたとき

Google Classroomに新しい教材が投稿されたら、同じ手順でダウンロードします。前の教材のフォルダは消さず、別のフォルダとして残しておきます。日付と末尾の英数字が名前に入っているので、別の版は同じ場所に置いても混ざりません。自分が作ったプロジェクトは 書類 の Kotlin フォルダにあり、教材とは別なので、教材を入れ替えても消えません。

  1. このフォルダを、Finderの左側の 書類 へドラッグして移動します。
  2. 移動した先のフォルダをダブルクリックして開き、中身を確認します。

成功の目印

「書類」の中のフォルダを開くと、docs と samples という2つのフォルダと、はじめに.txt、VERSION.json という2つのファイルがある。翻訳を含む版では、言語を選ぶ入口の index.html もあり、合わせて5つになる。

index.html があるとき

index.html をブラウザで開き、読む言語を選びます。日本語で読むときは、このページをそのまま読み進めて構いません。index.html がない版では、このページをそのまま読み進めます。上の4つのうち、足りないものがあるときだけ、先に進まずに先生に見せてください。

どの版（バージョン）の教材かを見分ける

教材は、授業の進み方に合わせて新しい版が配られます。手もとのものがどの版かは、次の2か所で分かります。

見る場所分かること
フォルダ名の日付と末尾の12文字上の例なら 2026-09-23 と a81c6585fd87 の組で版を見分けます。同じ日付でも、末尾が違えば別の版です。
VERSION.json の中の version版の名前です。materials- のあとに、年月日と英数字が続く形になっています。

先生に質問するときは、ここに書いてある版の名前を伝えると、話が早く進みます。VERSION.json の中身は書き換えないでください。

新しい版をもらったときも、同じことをします

この科目を受講している期間中に、先生から新しい版の教材が配られることがあります。そのときも、この手順のまま「書類」へ移動してください。日付か末尾の英数字が違えば、前のものとは別のフォルダになり、混ざりません。古いほうは消さずに残しておいて大丈夫です。日付も末尾も同じなら、同じ版です。

授業中は、先生が使う版の日付と末尾の英数字を示します。開く前に、フォルダ名を先生の案内と照合してください。

ダウンロードしたものが見つからない・名前が少し違う

同じ教材を2回ダウンロードすると、名前のうしろに (1) や -2 が付くことがあります。これは、すでにあるファイルやフォルダと区別するために付いた印で、版を表す12文字とは別です。先生の案内と日付・12文字を照合し、分からなければ先生に見せてください。

2. 使うものを確かめる

この授業は、1コマ90分で、全15コマあります。前半（1コマ目から6コマ目）と後半（7コマ目から15コマ目）で、使うアプリが変わります。学校から貸し出されているMacには、IntelliJ IDEA と Android Studio の両方があらかじめ入っています。自分で入れる作業はありません。

使うものいつ使うか何をするか
ブラウザ（Kotlin Playground）最初の1回だけ準備なしでKotlinのコードを実行し、動くことを確かめます。
IntelliJ IDEA前半Kotlinのプログラムを書いて、結果を文字で確かめます。スマートフォンの画面は作りません。
Android Studio後半Kotlinでスマートフォンのアプリを作り、画面で確かめます。

2つとも開けることを確かめる

Launchpad を開くか、Finderの アプリケーション フォルダを見て、IntelliJ IDEA と Android Studio の2つがあることを確かめます。前半で使うのは IntelliJ IDEA だけですが、いま両方あることを見ておくと、後半で慌てずに済みます。

ここで止まって、確認

どちらかが見つからないときは、自分で入れようとせず、その画面のまま先生に知らせてください。

版（バージョン）について

IntelliJ IDEA も Android Studio も、版がいくつも公開されています。貸与されたMacに入っている版をそのまま使ってください。自分で新しい版を探して入れ直す必要はありません。版が少し違っても、多くの操作はそのまま進められます。いま使っている版は、それぞれのWelcome画面の左上に出ます。

アプリこの教材での扱い
IntelliJ IDEA版は指定しません。教員は 2026.3 EAP で教材を確認しています。
Android Studio後半の教科書は、授業の基準である Panda 2 の画面とメニュー名で書いています。

版が違った・アプリが見つからない

版が違うと、ボタンの名前や並びが教科書と少し違うことがあります。探しても見つからないときは、自分で設定を変えたり入れ直したりせず、その画面のまま先生に見せてください。

3. 後半で使う Android Studio とエミュレータ

7コマ目からは、Android Studio でスマートフォンのアプリを作ります。作ったアプリは、エミュレータ（Macの中で動く練習用のAndroid端末）で動かします。

この準備の段階では、エミュレータを作る必要はありません。作り方は、後半の A01：HelloAndroidのSTEP 02 で先生と確認します。ここでは、使う端末の名前だけ覚えておいてください。

決めるものこの授業での指定
エミュレータの名前jec_25cm_kotlin_Pixel 9a
作る場所Android Studio の Device Manager

名前は1文字も変えないでください

教科書の説明は、この名前で書いてあります。Pixel と 9a の間は半角スペースです。下線の記号ではありません。名前が違うと、実行するときにどの端末を選べばよいか分からなくなります。

後半で作るAndroidのプロジェクトも、前半と同じ ~/Documents/Kotlin の中に置きます。前半のプロジェクトを消す必要はありません。

Android Studio でも、書くのはKotlinです

前半で覚えた書き方は、そのまま使います。違うのは、結果が文字で出るか、スマートフォンの画面に出るかです。前半でつまずいたところは、後半に入る前に先生に聞いておいてください。

完成プロジェクト（先生が作った見本）の開き方

手順1で「書類」に置いた教材のフォルダの中の samples に、完成プロジェクトがそのまま開ける形で入っています。ダウンロードも展開も要りません。前半のKotlinのプロジェクトは IntelliJ IDEA の Open、後半のAndroidのプロジェクトは Android Studio の Open で、samples の中のフォルダを選びます。

ここまでできたら、準備は終わりです。第1単元の教科書を開いて授業を始めましょう。

4. うまくいかないとき

出たもの・起きたことやってみること
ダウンロードしたフォルダの名前に (1) や -2 が付いている古い教材を開いている可能性がある。自分で判断せず先生に見せる。
Macに IntelliJ IDEA や Android Studio が見つからない貸与されたMacには入っているはずなので、自分で入れようとせず、先生に知らせる。
前に作ったプロジェクトの場所が分からないFile → Open Recent に出ていないか見る。~/Documents/Kotlin の中にあるはず。
教科書に書いてある名前が、自分の画面にないIntelliJ IDEA や Android Studio の版が違うことがある。設定を変えず、その画面のまま先生に見せる。

表にないことが起きたら、その画面のまま先生に見せてください。質問するときは、VERSION.json に書いてある教材の版を伝えてください。プロジェクトの作成やコードの実行で困ったときは、各教科書の「困ったとき」を見てください。
