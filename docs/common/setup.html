KOTLIN PROGRAMMING EXERCISES / 共通資料・授業サポート

授業を始めるまでの
準備

教材を受け取ってから、はじめてのKotlinのプログラムが動くまで。上から順に1回だけ行います。まずブラウザだけで動かし、そのあとIntelliJ IDEAに移ります。2回目からは、教科書を開くところから始められます。

この資料の流れ

① 教材を受け取る→② 使うものを確かめる→③ ブラウザで動かす→④ プロジェクトを作る→⑤ 実行して結果を読む→⑥ 後半の準備を知る

番号は、下の見出しの番号と同じです。②では、使うアプリがMacに入っていることを確かめます。③はブラウザだけで終わります。④で1行だけTerminalを使い、そのあとはIntelliJ IDEAの画面で操作します。うまくいかないときは、いちばん下の「7. うまくいかないとき」を見てください。

JavaやSwiftとの違いだけを書いています

この資料は、エディタの使い方そのものは説明しません。書いてあるのは、Kotlinのプロジェクトの作り方と、IntelliJ IDEAでの実行のしかただけです。JavaやSwiftで同じことをやってきた経験は、そのまま使えます。

この準備が終わると

ブラウザとIntelliJ IDEAの両方で、Kotlinのプログラムを実行し、その結果を読めるようになります。ここまでできれば、第1単元の教科書を開いて始められます。

1. 教材を受け取り、「書類」に置く

授業で使う教科書は、ZIPファイル1つにまとめて Google Classroom で配られます。ダウンロードして、置き場所を決めるところまでを行います。

  1. ブラウザで Google Classroom を開き、この授業のクラスを選びます。先生が投稿した教材のお知らせに、ZIPファイルが添付されています。
  2. 添付されたZIPファイルをクリックして、ダウンロードします。
  3. Finderを開き、左側の ダウンロード をクリックします。
  4. いちばん上に、今ダウンロードしたものがあります。次の2つのどちらかです。
ダウンロードにあるものすること
名前が .zip で終わるファイルダブルクリックします。同じ名前のフォルダができます。
すでにフォルダになっているそのままで大丈夫です。ZIPファイルが自動で展開され、同じ名前のフォルダができています。

どちらの場合も、最後はフォルダが1つある状態になります。名前には、次のように日付と12文字の英数字が入ります。

ZIPファイルの名前の例
kotlin-student-materials-2026-09-23-a81c6585fd87.zip
展開してできるフォルダの名前の例
kotlin-student-materials-2026-09-23-a81c6585fd87

日付と、そのうしろの12文字の英数字で教材の版を見分けます。同じ日に配られた教材でも、末尾が違えば別の版です。配られた版によって変わるので、上の例と同じ名前でなくても構いません。

新しい教材が配られたとき

Google Classroomに新しい教材が投稿されたら、同じ手順でダウンロードします。前の教材のフォルダは消さず、別のフォルダとして残しておきます。日付と末尾の英数字が名前に入っているので、別の版は同じ場所に置いても混ざりません。自分が作ったプロジェクトは 書類 の Kotlin フォルダにあり、教材とは別なので、教材を入れ替えても消えません。

  1. このフォルダを、Finderの左側の 書類 へドラッグして移動します。
  2. 移動した先のフォルダをダブルクリックして開き、中身を確認します。

成功の目印

「書類」の中のフォルダを開くと、docs と samples という2つのフォルダと、はじめに.txt、VERSION.json という2つのファイルがある。翻訳を含む版では、言語を選ぶ入口の index.html もあり、合わせて5つになる。

index.html があるとき

index.html をブラウザで開き、読む言語を選びます。日本語で読むときは、このページをそのまま読み進めて構いません。index.html がない版では、このページをそのまま読み進めます。上の4つのうち、足りないものがあるときだけ、先に進まずに先生に見せてください。

どの版（バージョン）の教材かを見分ける

教材は、授業の進み方に合わせて新しい版が配られます。手もとのものがどの版かは、次の2か所で分かります。

見る場所分かること
フォルダ名の日付と末尾の12文字上の例なら 2026-09-23 と a81c6585fd87 の組で版を見分けます。同じ日付でも、末尾が違えば別の版です。
VERSION.json の中の version版の名前です。materials- のあとに、年月日と英数字が続く形になっています。

先生に質問するときは、ここに書いてある版の名前を伝えると、話が早く進みます。VERSION.json の中身は書き換えないでください。

新しい版をもらったときも、同じことをします

この科目を受講している期間中に、先生から新しい版の教材が配られることがあります。そのときも、この手順のまま「書類」へ移動してください。日付か末尾の英数字が違えば、前のものとは別のフォルダになり、混ざりません。古いほうは消さずに残しておいて大丈夫です。日付も末尾も同じなら、同じ版です。

授業中は、先生が使う版の日付と末尾の英数字を示します。開く前に、フォルダ名を先生の案内と照合してください。

ダウンロードしたものが見つからない・名前が少し違う

同じ教材を2回ダウンロードすると、名前のうしろに (1) や -2 が付くことがあります。これは、すでにあるファイルやフォルダと区別するために付いた印で、版を表す12文字とは別です。先生の案内と日付・12文字を照合し、分からなければ先生に見せてください。

2. 使うものを確かめる

この授業は、1コマ90分で、全15コマあります。前半（1コマ目から6コマ目）と後半（7コマ目から15コマ目）で、使うアプリが変わります。学校から貸し出されているMacには、IntelliJ IDEA と Android Studio の両方があらかじめ入っています。自分で入れる作業はありません。

使うものいつ使うか何をするか
ブラウザ（Kotlin Playground）最初の1回だけ準備なしでKotlinのコードを実行し、動くことを確かめます。
IntelliJ IDEA前半Kotlinのプログラムを書いて、結果を文字で確かめます。スマートフォンの画面は作りません。
Android Studio後半Kotlinでスマートフォンのアプリを作り、画面で確かめます。

2つとも開けることを確かめる

Launchpad を開くか、Finderの アプリケーション フォルダを見て、IntelliJ IDEA と Android Studio の2つがあることを確かめます。前半で使うのは IntelliJ IDEA だけですが、いま両方あることを見ておくと、後半で慌てずに済みます。

ここで止まって、確認

どちらかが見つからないときは、自分で入れようとせず、その画面のまま先生に知らせてください。

版（バージョン）について

IntelliJ IDEA も Android Studio も、版がいくつも公開されています。貸与されたMacに入っている版をそのまま使ってください。自分で新しい版を探して入れ直す必要はありません。版が少し違っても、多くの操作はそのまま進められます。いま使っている版は、それぞれのWelcome画面の左上に出ます。

アプリこの教材での扱い
IntelliJ IDEA版は指定しません。教員は 2026.3 EAP で教材を確認しています。
Android Studio後半の教科書は、授業の基準である Panda 2 の画面とメニュー名で書いています。

版が違った・アプリが見つからない

版が違うと、ボタンの名前や並びが教科書と少し違うことがあります。探しても見つからないときは、自分で設定を変えたり入れ直したりせず、その画面のまま先生に見せてください。

3. ブラウザだけで動かす（Kotlin Playground）

Kotlin Playground は、JetBrainsが公開しているWebサービスです。アプリの用意も、プロジェクトの作成もせずに、ブラウザのページ上で fun main() をそのまま実行できます。最初の1回は、ここでKotlinのコードが動くことを確かめます。

  1. ブラウザで https://play.kotlinlang.org/ を開きます。エディタと、その上に並んだボタンが表示されます。
  2. エディタに最初から入っているコードをすべて消し、次の3行を書きます。
Kotlin Playground · エディタ
fun main() {
    println("Hello, Kotlin")
}
  1. 右上の Run ボタン（▶）をクリックします。
  2. ページの下に実行結果のウィンドウが自動で開き、出力が表示されます。
実行結果のウィンドウに出るもの
Hello, Kotlin

成功の目印

実行結果のウィンドウに Hello, Kotlin と出ている。

画面の使い方

使うのは、次の4つだけです。残りのボタンは授業では触りません。

場所何をするもの
Kotlinの版を選ぶメニュー既定で最新の版が選ばれています。変更しません。
Run ボタン（▶）書いたコードを実行します。
実行結果のウィンドウ実行すると自動で開きます。println の出力とエラーが、ここに出ます。
共有ボタンいま書いているコードのURLを作ります。先生にコードを見せたいときだけ使います。

実行の入口（JavaやSwiftとの違い）

Kotlinは、main をクラスの中に入れる必要がありません。ファイルの一番外側に fun で書けば、それが入口になります。

言語実行の入口の書き方
Kotlinfun main()。クラスは要りません。引数の args も、使わないなら省けます。
Javapublic static void main(String[] args)。クラスの中に置きます。
Swiftmain.swift のトップレベルに書いたコード、または @main を付けた型の static func main()。

Playgroundは最初の1回だけ

Playgroundには2つの弱点があります。コード補完が効きません。そして、実行結果が出るまでに時間がかかります（実行はサーバ側で行われるためです）。授業で書く量になると、この2つがそのまま手間になります。動くことを確かめたら、次の手順4からは IntelliJ IDEA に移ってください。

4. IntelliJ IDEA でKotlinのプロジェクトを作る

この授業で作るプロジェクトは、すべて ~/Documents/Kotlin の下に置きます。まず、その置き場所を作ります。

Terminal · 打ち込む
mkdir -p ~/Documents/Kotlin

何も表示されずに入力待ちに戻れば成功です。すでに作ってあっても、エラーにはなりません。Terminalを使うのは、この1行だけです。

新しいプロジェクトを作る

  1. IntelliJ IDEA の Welcome画面で New Project をクリックします。すでにプロジェクトが開いているときは、File → New → Project… を選びます。
  2. 左の一覧で New Project が選ばれていることを確かめます。
  3. 右側の項目を、次のように設定します。
項目入れるもの
Name先生が指定したプロジェクト名。第1単元では K01HelloKotlin です。
Location/Users/ユーザ名/Documents/Kotlin
LanguageKotlin
Build systemIntelliJ
JDK一覧に出てくるもののうち、いちばん番号が大きいもの
Add sample codeチェックを外す

Location にはプロジェクト名を含めません。Location の下に、実際にできる場所が小さな文字で表示されるので、そこが Documents/Kotlin の下になっているか確かめてください。ユーザ名 の部分は、Macにログインしている自分の名前です。

Build system は IntelliJ を選びます

ほかに Maven と Gradle が並んでいます。前半の授業では外部のライブラリを使わないので、ビルドツールを挟まない IntelliJ のままにしてください。後半のAndroidの単元では、Android Studioが Gradle を使います。そちらは自分で選ぶ必要がありません。

  1. Create をクリックします。新しいウィンドウが開きます。
  2. 左側の Project の一覧に、プロジェクト名のフォルダが出ます。その中に src というフォルダがあります。

成功の目印

左側の一覧にプロジェクト名が出ていて、その下に src がある。

Location は、次からも同じ場所が入っています

2回目にプロジェクトを作るときは、Location に前回の場所が最初から入っています。/Users/ユーザ名/Documents/Kotlin のままかどうかだけ、毎回確かめてください。別の場所に作ってしまうと、あとで自分のファイルを見つけられなくなります。

5. fun main() を実行して、結果を読む

ファイルを作って、3行書く

  1. 左側の一覧で src を右クリックし、New → Kotlin Class/File を選びます。
  2. 名前の欄に main と打ち、下の一覧から File を選んで Enter を押します。
  3. main.kt というファイルができて、右側に編集画面が開きます。
  4. 次の3行を打ち込みます。
main.kt
fun main() {
    println("はじめまして")
}

ファイル名とクラス名を合わせる必要はありません。Kotlinでは、トップレベルの関数をそのまま書けます。書いたものは自動で保存されるので、保存の操作も要りません。

実行する

fun main() と書いた行の左、行番号のとなりに緑の三角（▶）が出ます。これが実行ボタンです。

  1. 緑の三角（▶）をクリックします。
  2. 出てきたメニューから Run 'MainKt' を選びます。
  3. ウィンドウの下に Run ツールウィンドウが開き、結果が出ます。
Run ツールウィンドウに出るもの
はじめまして

Process finished with exit code 0

メニューに出る MainKt は、main.kt をコンパイルしてできるクラスの名前です。Kotlinのトップレベルの関数は、ファイル名から作られたこの名前のクラスに、static メソッドとして入ります。JavaからKotlinのコードを呼べるのは、この仕組みがあるためです。

出ている行意味
いちばん上にある、長い英数字の行IntelliJ IDEA が組み立てた実行コマンドです。出ないこともあります。
真ん中の行println で出した文字です。授業で確かめるのは、ここです。
Process finished with exit code 0正常に終わりました。
Process finished with exit code 1途中で止まりました。この行の上に、赤い文字で理由が出ています。

成功の目印

Run ツールウィンドウに はじめまして と出て、その下に Process finished with exit code 0 がある。

Run ツールウィンドウを閉じてしまったとき

上のメニューの View → Tool Windows → Run で、もう一度出せます。⌘ Command + 4 でも開きます。前の結果は消えていません。

2回目からは、右上の ▶ で実行できます

一度実行すると、その実行の設定が記憶され、ウィンドウの右上の実行ボタン（▶）から同じプログラムを動かせます。別のファイルを開いているときでも、動くのは記憶されたほうです。違うファイルを実行したいときは、そのファイルの行番号のとなりの緑の三角を使ってください。

ここまでできたら、前半の準備は終わりです。次の授業からは、教科書を開くところから始められます。

6. 後半で使う Android Studio とエミュレータ

7コマ目からは、Android Studio でスマートフォンのアプリを作ります。作ったアプリは、エミュレータ（Macの中で動く練習用のAndroid端末）で動かします。

この準備の段階では、エミュレータを作る必要はありません。作り方は、後半の A01：HelloAndroidのSTEP 02 で先生と確認します。ここでは、使う端末の名前だけ覚えておいてください。

決めるものこの授業での指定
エミュレータの名前jec_25cm_kotlin_Pixel 9a
作る場所Android Studio の Device Manager

名前は1文字も変えないでください

教科書の説明は、この名前で書いてあります。Pixel と 9a の間は半角スペースです。下線の記号ではありません。名前が違うと、実行するときにどの端末を選べばよいか分からなくなります。

後半で作るAndroidのプロジェクトも、前半と同じ ~/Documents/Kotlin の中に置きます。前半のプロジェクトを消す必要はありません。

Android Studio でも、書くのはKotlinです

前半で覚えた書き方は、そのまま使います。違うのは、結果が文字で出るか、スマートフォンの画面に出るかです。前半でつまずいたところは、後半に入る前に先生に聞いておいてください。

完成プロジェクト（先生が作った見本）の開き方

手順1で「書類」に置いた教材のフォルダの中の samples に、完成プロジェクトがそのまま開ける形で入っています。ダウンロードも展開も要りません。前半のKotlinのプロジェクトは IntelliJ IDEA の Open、後半のAndroidのプロジェクトは Android Studio の Open で、samples の中のフォルダを選びます。
